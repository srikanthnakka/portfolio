# Problem Statement

IPL match datasets contain hundreds of thousands of ball-by-ball records.
Without structured analysis, it is difficult to answer strategic questions such as:

* Do teams perform better when **chasing targets**?
* Which venues produce **high-scoring matches**?
* Which players consistently deliver strong performances?
* How has **scoring evolved across IPL seasons**?

This project builds a **complete analytics workflow** to convert raw match data into actionable insights.

---

# Why This Analysis Matters

Sports analytics plays a major role in helping teams and analysts make **data-driven strategic decisions**.

Insights from this analysis can help:

* understand team strategies such as chasing vs defending
* identify consistent high-performing players
* evaluate venue conditions and scoring behavior
* analyze scoring trends across IPL seasons

This project demonstrates how **data analytics can uncover meaningful patterns in sports performance data**.

# Key Insights

Key insights discovered during the analysis include:

* Chasing teams win approximately **52.6% of IPL matches**
* Average first innings score across IPL seasons is **167 runs**
* **Virat Kohli** is the highest run scorer in IPL history
* **Yuzvendra Chahal** leads IPL wicket tallies
* Run rates have steadily increased across recent seasons

These findings highlight how **data analytics can reveal strategic patterns in sports performance**.
